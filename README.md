# Pocket Notes

A notes app for Windows with a canvas for text boxes and pictures, reminders, and Pip,
a little pilot duck (with an optional AI that runs entirely on your own computer).

## Install

1. Go to **[Releases](../../releases/latest)** and download `PocketNotesSetup.exe`.
2. Run it. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**
   (the installer isn't signed with a paid certificate).

No administrator rights are needed. Your notes are kept in `Documents\Pocket Notes`.

## Updates

Pocket Notes checks this page once a day and offers new versions (Settings › About ›
Check for updates). Updating keeps your notes and settings.
